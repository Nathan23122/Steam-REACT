# Cahier des charges

Il s'agit d'une application pour parcourir des jeux steams. L'application aura les pages suivantes :
 - affichage de toutes les catégories
 - affichage de tous les jeux d'une catégorie donnée
 - affichage de tous les jeux pour une recherche
 - affichage d'un jeu contenu son nom, une description, une image, des prix...
